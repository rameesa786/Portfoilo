AI-powered Resume Screening & Ranking

Streamlined Candidate Evaluation with NLP & Machine Learning

This intelligent system streamlines the hiring process by analyzing resumes using NLP techniques and ranking candidates based on job-fit scores. It reduces manual screening time and ensures data-driven, unbiased selection.

📄 Resume Parser

Extracts key sections like education, skills, experience, and projects automatically.

⚙️ Skill Matching

Uses TF-IDF & cosine similarity to compare resume content with job description.

📊 Scoring & Ranking

Ranks candidates based on configurable weights for various resume sections.

🚀 Deployment

Deployed using Streamlit, ensuring a smooth and interactive recruiter experience.
