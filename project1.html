ReMedIntel

AI-powered platform predicting patient hospital readmission using PCA & hybrid ML models to support smarter healthcare decisions.

📌 Overview

ReMedIntel is a predictive analytics application built with Streamlit. It helps hospitals forecast patient readmissions, reduce healthcare costs, and improve patient outcomes by leveraging dimensionality reduction (PCA) and multiple ML models.

⚙️ Features

  • Predict readmission by patient name with personalized insights.
  • Forecast patients likely to be readmitted within a time window (e.g., next 5 days).
  • Handles under observation & deceased cases gracefully.
  • Interactive dashboard for hospital staff with real-time results.

🧠 Technical Highlights

  • Preprocessing: Label encoding, PCA (3D feature reduction).
  • Models: Logistic Regression, Decision Tree, Deep Learning (Keras).
  • Tools: Pandas, Scikit-learn, TensorFlow, Joblib, Streamlit.

📊 Results & Impact

By predicting readmissions, the system empowers hospitals to take proactive measures:

  • Reduce avoidable readmissions.
  • Improve patient care & resource allocation.
  • Support data-driven decisions for healthcare staff.
